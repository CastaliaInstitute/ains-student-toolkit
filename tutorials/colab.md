# Google Colab Basics

Google Colab is a browser-based notebook environment. It lets you run course notebooks without installing Python on your computer.

## Open a course lab

1. Open the lab link from the course page. Prefer the course’s labeled **Open in Colab** link.
2. Sign in to a Google account if prompted. This is separate from GitHub sign-in.
3. Choose **File → Save a copy in Drive** before making changes. The course’s original notebook is a reference copy; your saved copy is where your work persists.
4. Keep the default CPU runtime unless your course explicitly requires a different one.
5. Use **Runtime → Run all** to run the notebook from the beginning. Read the explanations and outputs as you go.
6. Follow the activity instructions to change one input or setting, rerun the relevant cells, and note the difference.
7. Submit the saved notebook link or exported `.ipynb` file only in the way your instructor specifies.

## What Colab does and does not do

- Colab runs notebook code in a temporary cloud **runtime**.
- Saving a copy in Drive preserves your notebook edits. Runtime files and variables may reset when the runtime disconnects.
- Colab does not automatically submit work to your course site.
- A Colab notebook opened from a public GitHub repository can usually be read without GitHub sign-in. Saving and running your own copy uses your Google account.
- A course may also use GitHub for a separate assignment. Colab access does not grant access to a private GitHub classroom.

## If a course activity mentions GitHub

Check the assignment instructions. Some activities only use Colab; others ask you to sign in to GitHub, accept a course invitation, or submit a link. See [GitHub basics](github.md) and [Troubleshooting](troubleshooting.md).
