# Troubleshooting

When asking for help, include the course and module, the tool you used, the link you opened, the step that failed, and the exact error text. A screenshot can help. Never send passwords, one-time codes, API keys, or private student data.

## Sign-in and access

### GitHub says “Unauthorized”

GitHub access is separate from Google/Colab access. Check that you are signed in to the account invited to the course, then accept the classroom or organization invitation. If the page still fails, send support the link, intended username, and exact message.

### GitHub shows a 404

A private repository or unaccepted invitation may not be visible to your current account. Confirm the account and invitation before concluding the file is missing.

### Colab asks me to sign in

Colab uses a Google account. Sign in, then save a personal copy in Drive before editing.

## Notebook and Python

### The notebook says a variable is not defined

A previous cell may not have run. Choose **Runtime → Run all** or run the cells from the top in order.

### The runtime disconnected or my variables disappeared

A runtime is temporary. Reconnect and run the cells again. Your notebook edits remain in the saved Drive copy, but unsaved files in the temporary session may be lost.

### A cell runs but the result is unexpected

Check the input value, the order cells were run, and whether the instructions asked for a particular runtime. Change one thing at a time.

## Submission

### I saved my notebook but do not know if it was submitted

Saving to Drive and submitting to the course are separate actions. Return to the assignment instructions and use the specified submission route. If unclear, ask your instructor before submitting sensitive material to a public repository.
