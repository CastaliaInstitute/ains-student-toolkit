# GitHub Basics

GitHub hosts project files and keeps a history of changes. A **repository** (often shortened to **repo**) is a project folder with that history.

## What students may need to do

Course instructions may ask you to read a public repository, accept a classroom invitation, make a change, or submit work. These are different tasks and may have different access requirements.

- **Read a public repository:** usually possible in a browser without signing in.
- **Accept an invitation or edit a repository:** requires signing in to the correct GitHub account and having access granted.
- **Submit a change:** follow the course’s stated method. It may ask you to upload a file, make a commit, or open a pull request.

## The core ideas

- **Repository:** the project and its tracked files.
- **Commit:** a saved checkpoint describing a set of changes.
- **Branch:** a separate line of work, so changes can be prepared without altering the main version.
- **Pull request:** a request to review and bring changes from one branch into another.
- **Classroom invitation:** a course link that grants access to a particular assignment or repository after you accept it.

You do not need to learn command-line Git to read course materials or complete a Colab-only activity.

## If you see “Unauthorized” or “404”

1. Note the exact page or assignment link and the message shown.
2. Check which GitHub account is currently signed in. If you have more than one account, switch to the one used for the course invitation.
3. Check your email and GitHub notifications for an invitation, and accept it if present.
4. If it still fails, send course support the link, the account username you intended to use, and a screenshot or exact error text. Do not send your password or authentication code.
5. Do not assume the assignment is missing from a 404 alone; private repositories and unaccepted invitations can look similar.

For Colab, use your Google account; GitHub authorization and Google sign-in are separate. See [Colab basics](colab.md) and [Troubleshooting](troubleshooting.md).
