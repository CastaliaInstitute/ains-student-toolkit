# AINS Student Glossary

Plain-language definitions for tool and AI terms used across AINS courses. Course materials should link the first important use of a term to its definition here. Use stable anchors in the form `../glossary/README.md#term`.

## AI and course concepts

- <a id="ai-system"></a>**AI system** — A system that uses a method associated with artificial intelligence to produce predictions, recommendations, content, or actions. It includes people, data, software, and the setting where it is used—not just a model.
- <a id="algorithm"></a>**Algorithm** — A defined set of steps for solving a problem or carrying out a computation.
- <a id="artificial-intelligence"></a>**Artificial intelligence (AI)** — A broad field concerned with building or studying systems that perform tasks associated with perception, language, learning, reasoning, planning, or decision support.
- <a id="baseline"></a>**Baseline** — A simple or existing approach used as a reference when judging whether a new method helps.
- <a id="dataset"></a>**Dataset** — A collection of examples or records used to explore, train, or evaluate a system.
- <a id="feature"></a>**Feature** — An input detail a model or rule uses, such as an age band, word count, or measured signal.
- <a id="generative-ai"></a>**Generative AI** — AI that produces new content, such as text, images, audio, or code, in response to input.
- <a id="large-language-model"></a>**Large language model (LLM)** — A model trained on large amounts of text to process and generate language. It can produce plausible answers that are inaccurate, so outputs need evaluation.
- <a id="machine-learning"></a>**Machine learning** — Methods that use data to fit patterns or make predictions, rather than relying only on rules written by a person.
- <a id="model"></a>**Model** — A computational representation that maps inputs to outputs according to learned patterns, written rules, or another formal method.
- <a id="prompt"></a>**Prompt** — The instructions and information provided to a generative AI model as input.
- <a id="synthetic-data"></a>**Synthetic data** — Artificially generated examples used for practice or analysis. Results on synthetic data do not by themselves prove how a system will behave on real cases.

## Python and notebooks

- <a id="cell"></a>**Cell** — A block in a notebook. A code cell runs Python; a text cell explains or documents the work.
- <a id="function"></a>**Function** — A named set of instructions that can be run with inputs and may return a result.
- <a id="jupyter-notebook"></a>**Jupyter notebook** — An interactive document that combines text, code, and results. The common file extension is `.ipynb`.
- <a id="library"></a>**Library** — Reusable code that provides functions for common tasks.
- <a id="python"></a>**Python** — A widely used programming language. A course notebook may let you use Python without installing it on your own computer.
- <a id="runtime"></a>**Runtime** — The computer session that executes notebook code. A cloud runtime can disconnect or reset, so save your notebook separately.
- <a id="string"></a>**String** — A piece of text in Python, usually written inside quotation marks.
- <a id="variable"></a>**Variable** — A name used to refer to a value in a program.

## Google Colab

- <a id="colab"></a>**Google Colab** — A browser-based service for opening and running Jupyter notebooks. It uses Google sign-in and can save notebook copies to Google Drive.
- <a id="gemini"></a>**Gemini** — Google's generative AI assistant. In Colab, availability and features depend on the signed-in account, age, region, and Google settings. Verify setup advice against your course instructions.

## GitHub and project work

- <a id="branch"></a>**Branch** — A separate line of work in a repository, used to prepare changes without changing the main version directly.
- <a id="codespaces"></a>**GitHub Codespaces** — A browser-based development environment connected to a GitHub repository.
- <a id="copilot-chat"></a>**GitHub Copilot Chat** — A conversational assistant in supported GitHub and code-editor experiences. In a Codespace it can answer questions about the open workspace when the signed-in account has Copilot access; it may be unavailable under some account or organization policies.
- <a id="commit"></a>**Commit** — A saved checkpoint of changes in a Git repository, usually accompanied by a short description.
- <a id="github"></a>**GitHub** — A web service for hosting Git repositories and collaborating on projects.
- <a id="git"></a>**Git** — A version-control tool that records changes to files over time.
- <a id="pull-request"></a>**Pull request (PR)** — A request to review and merge changes from one branch into another.
- <a id="repository"></a>**Repository (repo)** — A project folder whose files and change history are tracked with Git.
