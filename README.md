# AINS Student Toolkit

A practical, beginner-friendly guide to the tools used across Aurnova Institute of Networked Systems (AINS) courses. Use it when a course asks you to work with Python, notebooks, Google Colab, GitHub, or GitHub Codespaces.

**You do not need to learn every tool before starting your course.** Most readings work in a browser. Most guided labs can be opened in Colab. Use GitHub or Codespaces when the course activity specifically needs them.

## Choose your path

- **I just want to read course materials:** use the links in your course site. A GitHub account is not needed to read a public course page.
- **I need to run a lab:** start with [Colab basics](tutorials/colab.md). The course notebook opens in your browser; save your own copy to Google Drive before editing.
- **I need to understand the code:** use [Python basics](tutorials/python-basics.md) alongside the lab. You can begin by running and changing one clearly marked value.
- **My assignment asks for GitHub:** follow [GitHub basics](tutorials/github.md), then the course-specific submission instructions. Do not assume every assignment needs a GitHub account.
- **I need a complete project workspace:** follow [Codespaces basics](tutorials/codespaces.md) only when the course asks you to use it.
- **Something failed:** see [Troubleshooting](tutorials/troubleshooting.md).

## A useful first session

1. Open the course page in an up-to-date browser.
2. Read the activity instructions before opening a tool.
3. For a Colab lab, save a personal copy first, then run the notebook from top to bottom.
4. Change one named value, run the relevant cells again, and describe what changed in ordinary language.
5. Keep a note of the tool, step, and exact message if you need help.

## Scope

This repository explains common student workflows. Your course syllabus and instructor instructions determine which tools, submission method, and account are required for a specific activity. Never put passwords, API keys, private student data, or other secrets in a notebook or public repository.
