# AINS Student Toolkit

Welcome. This is the shared starting point for the digital tools used across AINS courses. The guides assume that you may be new to programming and give you a low-friction route into each activity.

## Start with the task you have

Prefer a guided sequence? [AINS5000: Programming Concepts and Tools for AI](https://aurnova.github.io/ains5000-course/book/intro.html) introduces GitHub, Colab, Codespaces, and basic Python through eight short modules. Use its [quick reference](https://aurnova.github.io/ains5000-course/book/reference.html) and [cross-course glossary](https://aurnova.github.io/ains5000-course/book/glossary.html) alongside graduate coursework.

| If you need to… | Start here |
|---|---|
| Read a course page | Course site; a GitHub login is not needed for public pages |
| Run an interactive lab | [Open and use Google Colab](tutorials/colab.md) |
| Understand or edit a few lines | [Python basics](tutorials/python-basics.md) |
| Save or submit work with GitHub | [GitHub basics](tutorials/github.md) |
| Open a full browser development environment | [GitHub Codespaces](tutorials/codespaces.md) |
| Ask a question about Python or these tool guides while working | [Copilot Chat in Codespaces](tutorials/codespaces.md#ask-the-toolkit-with-copilot-chat) |
| Recover from an error | [Troubleshooting](tutorials/troubleshooting.md) |
| Look up a course or tool term | [Glossary](glossary/README.md) |

**You can start without a computer science background.** Follow the activity instructions and learn only the tool steps that activity uses.
